# Agent harness brand assets

These files identify the external agent harness selected in Cohub. They must
remain subordinate to Cohub branding and should not imply endorsement.

- `codex-on-light.png`, `codex-on-dark.png`: official Codex application icons
  bundled with the OpenAI ChatGPT macOS application. Resized proportionally
  from 1024 px to 64 px for the compact web control.
- `pi-auto.svg`: official Pi mark from `https://pi.dev/logo-auto.svg`, linked by
  the `earendil-works/pi` project README. The source switches between its
  supplied black and white variants with `prefers-color-scheme`.
- `cursor-on-light.svg`, `cursor-on-dark.svg`: official 2D cube marks from the
  Cursor brand asset archive at `https://cursor.com/brand`.
- `grok-on-light.svg`, `grok-on-dark.svg`: official Grok logomarks from the
  SpaceXAI logo archive linked at `https://x.ai/legal/brand-guidelines`.

Retrieved on 2026-08-29. Use each mark exactly as supplied apart from
proportional sizing, and follow the corresponding owner's current brand terms.
