# Task Inspector

First-party Cohub App for task details, progress and outputs.

```bash
pnpm --filter @cohub/task-inspector dev
pnpm --filter @cohub/task-inspector typecheck
pnpm --filter @cohub/task-inspector build
cohub apps publish task-inspector --dir cohub-apps/task-inspector/dist --visibility public
```

Publish with no publisher scopes. See [shared documentation](../shared/README.md) for authorization, verification and rollout.
