# Cohub 安装版可靠性修复计划

2026-09-06。依据已确认的统一安装版规格、Pro 审阅和本机专家反馈继续开发。目标与能力保留范围不变，不另起产品或更换技术栈。本轮修改保留在本地，不沿用上一轮为咨询而给予的 GitHub 推送授权。

## 执行顺序

1. **启动、恢复与退出。** 窗口先于后端出现，安装及恢复期间保持可操作；后端恢复后自动接入原窗口。每一代 runtime 绑定自己的 relay，换实例必须停止旧 relay；退出屏障拒绝迟到 spawn、IPC 和重试。保留实例认证、进程归属检查、总启动截止时间和诊断现场。
2. **操作与结果完整性。** 先阻止已经发出的写请求因丢失响应而自动重放，再补稳定操作身份、持久结果与 ACK 恢复、未知结果核对及去重保留。不能以 outbox 单独宣称恰好执行一次。超时必须区分仍在运行、已取消和结果未知。
3. **本地身份及设备隔离。** 本机授权与云端令牌有效期解耦，保持实例与账号约束；首选设备失配不静默切换，缓存与迟到响应绑定账号和设备。不得清空数据来通过测试。
4. **完整文件链路。** 二进制、较大响应、请求头及响应头、上传地址与 CORS 一起处理。大小受限时明确失败，不伪装成功；图片、ZIP、上传与下载逐项实测，不减少交付能力。
5. **安装性能与升级。** 分阶段记录校验、解包、数据库、API、Web 的耗时。重新界定可信清单、安装回执和代码完整性验证，再做热启动快路径。相同运行内容受控比较直接随 app 分发与解包，不在证据不足时删除依赖或改变打包结构。
6. **候选验收。** 复核生产能力清单，运行旧版样本升级、数据及会话保留、断网和崩溃恢复、桌面及手机代表路径。签名、公证和正式生产切换仍是单独门槛，测试通过不等于正式分发授权。

上述条目是依赖顺序，不是允许提前省略后续门槛。每轮记录完成的具体范围与剩余项。

## 首批实现与协作

主 Agent 负责桌面窗口、runtime/relay 生命周期和整合验收。Grok Build 仅承担可独立实现的“写请求发出后不自动重放”任务，使用独立本地 worktree，写入限于 `apps/local-relay/node/core.mjs` 与其测试；不授权它改协议、身份、部署、依赖或其他文件。主 Agent 审阅补丁并重新运行测试后才整合。

本轮不增加核心配置、依赖、付费服务，不修改生产、旧 dev 或用户日常客户端，不推送、建 PR 或合并。运行只使用隔离测试目录与本轮自有进程。

## 验证要求

先保留可复现的失败，再修改，再验证实际状态与副作用。首批覆盖：启动失败后恢复、窗口关闭与重开、runtime 密钥轮换、凭据读取期间停止、旧 relay 迟到消息、快速重连与退出、写请求副作用已发生但响应丢失、读取重试以及重试总截止时间。

单元测试覆盖确定性竞态；真实子进程和 Electron 窗口检查覆盖实际生命周期。隔离故障注入不冒充完整安装包及生产能力验收。验证记录必须写实际命令、结果、未执行部分和剩余缺陷。

## 工具执行边界

Grok CLI 已做静态扫描并读取本机代理包装入口，确认使用现有安装且关闭自动更新。`VERDICT: LIMITED_EXEC_OK`。允许帮助、配置发现以及上述限定 worktree 内的编码和 Node 测试；禁止自动升级、依赖安装、真实业务请求、全局配置修改、远端写入和秘密文件读取。不会把本机日志、登录态或安装包交给 worker。

## 首批开发进展

启动窗口、状态订阅、重试及诊断入口已经实现。服务失败与窗口打开失败共用恢复流程，恢复后进入原窗口；关闭窗口不停止服务，再次打开复用当前实例。启动进程的就绪监听先于归属记录写入，避免丢失快速发出的 ready 消息；取消等待归属写入结束后再清理。

runtime 与 relay 按实例和启动代次绑定。停止使在途启动失效，旧 relay 的消息、错误与重试不能覆盖新实例或退出状态。替换必须等待旧进程实际退出；无法退出时保留归属、显示错误并阻止自动替换，不假装停止成功。重复 Retry 合并成一次恢复，未登记本地安装也能重试服务，不强迫重新登录。

写请求发出后遇到超时、连接断开或响应读取失败，返回 `local_api_outcome_unknown`，不再自动重放。GET 和尚未派发业务写入的认证等待保留既有重试及总截止时间。这只是防止本进程自动重复写入，不证明服务端幂等、跨进程去重或崩溃恢复。

Grok Build 的执行停在编辑步骤，没有写入补丁或交回验证结果。本项由主 Agent 接回实现与验证，未将 worker 会话结束计作任务完成。

验证中另修了两处直接相关的问题：命令执行测试提前删除数据目录、与仍在写状态的子进程竞争；窗口打开的迟到失败把“正在恢复”覆盖成最终错误。原失败日志、截图及测试输出保留。实际命令和验收范围见 [安装版部署与验证记录](2026-09-06安装版部署与验证记录.md)。

第 1 项仍需补“runtime 组长突然死亡、后代进程仍存活”的归属与清理方案，不能靠取消指纹校验或按端口杀进程解决。第 2 项只完成禁止自动重放，后续仍要稳定操作身份、持久结果和未知结果核对。第 3 至 6 项未被本轮替代，也未降低验收门槛。本轮没有重新生成 DMG、部署 Dev2、修改生产或推送远端；现有旧测试包不包含本批修复。
