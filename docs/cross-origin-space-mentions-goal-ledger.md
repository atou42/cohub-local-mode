## Confirmed data-flow gap

- Remote mention search knows that a result came from the cloud, but the inserted mention and persisted `_meta.mentions` record do not carry an origin.
- The Agent tool context receives only `space_id`; it cannot distinguish a cloud target from a missing local target.
- On a local node, the existing cloud cross-Space tool path assumes cloud-mounted storage and cannot read a cloud workspace over the public API.

## Scope decisions

- This goal delivers local-session to cloud-Space reads. Cloud-session to local-Space reads remain outside this phase because the upstream cloud Agent runtime cannot be changed from this local deployment.
- Cloud account credentials remain in the host Agent process. They must not enter the model prompt, tool parameters, sandbox environment, logs, or persisted turn content.
- Old mentions without origin are resolved authoritatively: an existing local row remains local; otherwise the cloud API must positively resolve the Space. Unknown targets must not be guessed.
